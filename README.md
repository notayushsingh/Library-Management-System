# 📚 Library Management System

A console-based Library Management System built using Java. This project focuses on practicing Object-Oriented Programming (OOP), classes, objects, encapsulation, and Java collections through a practical application.

## 🚀 Features

- Add Books: Add books using a unique Book ID, title, and author.
- Display Books: View all books stored in the library.
- Search Books: Find a book using its Book ID.
- Availability Status: Check whether a book is available.
- Interactive Menu: Simple command-line interface for navigation.

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Scanner

## ▶️ How to Run

1. Clone the repository

    `` git clone [YOUR_REPOSITORY_URL](https://github.com/notayushsingh/Library-Management-System) ``

2. Navigate to the project directory

   `` cd Library-Management-System ``

3. Compile the Java files

   `` javac Book.java Student.java Library.java Main.java ``

4. Run the application

    `` java Main ``
